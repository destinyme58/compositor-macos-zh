# Compositor 1.5.5 简体中文 macOS 12+ 发行说明

这是面向 Apple Silicon Mac 的社区简体中文兼容构建。它基于开源项目
[Compositor](https://github.com/robbietilton/Compositor) 1.5.5，按
[教程视频](https://www.bilibili.com/video/BV1KFWA65EgW/) 中的汉化编译工具
生成。

## 安装包

- 文件：`Compositor-v1.5.5-AppleSilicon-zh-Hans-macOS12+.dmg`
- 应用版本：1.5.5
- 架构：Apple Silicon（arm64）
- 最低系统：macOS 12.0
- 界面语言：简体中文
- SHA-256：`c4340f054a83b4c45ccaf0d7c2335bbd2111a4a17f9bb02d62cc55ce85ee8af5`
- 文件大小：9,744,068 字节

## 本版说明

- 使用中文界面和 macOS 12 兼容补丁。
- 保留上游 1.5.5 的图层、蒙版、滤镜、Camera Raw 和文件格式能力。
- 关闭应用内自动更新，避免升级至要求 macOS 26 的版本。
- 使用 ad-hoc 签名，未经过 Apple 公证。

## 验证

- `hdiutil verify`：通过
- 主程序：Mach-O 64-bit arm64
- `LSMinimumSystemVersion`：12.0
- 中文资源：`zh-Hans.lproj/Localizable.strings`
- 在 macOS 15.8.1 上完成启动、中文界面检查和 1920×1080 画布创建

## 安装

下载 DMG 和同名 `.sha256` 文件，校验后挂载 DMG，将 `Compositor.app` 拖入
“应用程序”。首次启动若被 Gatekeeper 拦截，右键应用选择“打开”，或前往
“系统设置 → 隐私与安全性”选择“仍要打开”。
